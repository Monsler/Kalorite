### Kalorite

Kalorite is a tiny Qt6 audio player that aims to be modern and easy-to-use;

![alt text](https://i.ibb.co/PZ7qvgFg/20261015-011114.png)

It supports:
- receiving lyrics
- lrc files
- audio cd
- downloading songs from links
- receiving album photo and song info (and also parsing it from metadata)
- spectrum analyzer like in winamp(yep it really whips the llama's ass)
- pattern visulizer
- plugins in lua
- tracks shuffling
- equalizing
